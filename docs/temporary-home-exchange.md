# החלפת דירות זמנית

לצד השכרה ומכירה ניתן לפרסם דירה להחלפה, עם עיר הדירה, עיר מבוקשת ותאריכי זמינות. במסך `/exchange` בוחרים את הדירה שמציעים, יעד ותאריכי כניסה ויציאה. ההצעות מתעדכנות אוטומטית אחרי הפסקה קצרה בהקלדה.

## כללי התאמה

- הדירה המוצעת חייבת להיות בבעלות המשתמש המחובר, במצב זמין ובסוג Exchange.
- שתי הדירות חייבות להיות זמינות במשך כל התקופה, ולא רק בחלק ממנה.
- יום היציאה אינו ליל אירוח; כניסה ויציאה באותו יום אינן תקופה תקינה.
- עיר היעד מותאמת במדויק אחרי הסרת רווחים והמרת אותיות לקטנות; אין התאמת מרחק גאוגרפי או אזורים סמוכים.
- דירות המשתמש עצמו ומודעות שהוסרו מההיצע אינן מוצעות.
- התאמות הדדיות מוצגות ראשונות: העיר שהצד השני מחפש זהה לעיר הדירה שהמשתמש מציע. תוצאות אחרות מסומנות כהתאמות יעד ותאריכים בלבד.
- ההצעות אינן הזמנה או התחייבות. אין שריון תאריכים, הסכם, סליקה או הודעות יזומות. נדרש תיאום בין הצדדים.

## מודעות ונתונים קיימים

המיגרציה `AddTemporaryHomeExchange` מוסיפה את שדות ההחלפה והקשר בין הודעה לשתי הדירות. מודעות קיימות מסומנות `Unspecified`; אין לנחש אם הן למכירה או להשכרה. אפשר להשלים סוג עסקה בעריכת מודעה.

מספר חדרים נשמר כ־decimal, לרבות בחיפושים שמורים, כדי לאפשר 3.5 חדרים. ירידה לגרסה הקודמת עלולה לאבד חלקי חדרים ושדות החלפה — יש לגבות לפני שחזור מיגרציה. המיגרציה עולה אוטומטית בהפעלת השרת לפי המנגנון הקיים. יש לבדוק על עותק בסיס הנתונים לפני שדרוג סביבת משתמשים.

שליחת הצעת החלפה שומרת את הנכס המבוקש, הדירה המוצעת והתאריכים. השרת בודק בעלות וזמינות שוב בזמן השליחה. מזהי הנכסים בהודעות נשמרים גם אם מודעה מוסרת, כדי לשמר הקשר; הקישור עשוי להוביל לנכס שכבר אינו קיים.

## בורר תאריכים

משתמשים ב־`react-hebrew-datepicker@1.1.3`, עם לוח עברי ולועזי. הערך נשאר `YYYY-MM-DD` ונשמר כ־DateOnly, ללא המרה ל־UTC. משמעות "היום" בבקשות ההחלפה היא יום ישראל.

`patches/react-hebrew-datepicker+1.1.3.patch` מתקן את ההמרה בין היום העברי לערך ISO: מסיר קידום מלאכותי ביום, מפיק תאריך מקומי ומפענח ערך מבוקר בצהרי היום המקומי. זה מונע תלות באזור הזמן. `postinstall` מחיל את התיקון גם ב־CI וב־Docker. בשדרוג הספרייה יש לבדוק אם התיקון כבר נכלל בה ולהריץ את בדיקות הבורר לפני הסרתו.

## בדיקות

```sh
cd domix-client
npm ci
npm run typecheck
npm run lint
npm test
npm run build
TZ=Asia/Jerusalem npx vitest run src/components/ui/HebrewDateField.test.tsx
TZ=America/Los_Angeles npx vitest run src/components/ui/HebrewDateField.test.tsx
```

```sh
dotnet test domix-server.Tests
```

לבדיקה ידנית: לפרסם שתי דירות בשתי ערים עם יעדים הפוכים ותקופות חופפות; לבדוק התאמה הדדית, תקופה שמכוסה רק בחלקה, דירה של משתמש אחר, מודעה לא זמינה ופנייה שמציגה את שתי הדירות בתיבת ההודעות. לבדוק חזרה מהנכס לחיפוש, רענון כתובת וסינון מכירה/השכרה/החלפה, לרבות חיפוש שמור.

הגישה לקטלוג ולחיפוש נשארת מבוססת חשבון. פתיחת מאגר ציבורי מצריכה החלטה אילו פרטי כתובת וזהות מיועדים לפרסום.
