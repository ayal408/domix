# טיוטת בקשת בדיקה לנטפרי — DOMIX

מצב: טיוטה בלבד; לא נשלחה. כתובת האתר וקישורי החשבון יושלמו אחרי פריסה מאומתת. אין להציג את מצייני המקום ככתובות קיימות.

**נושא:** בקשת בדיקת אתר DOMIX ושירותי הניהול הנדרשים להפעלתו

שלום וברכה,

אני מפתחת את DOMIX, אתר לפרסום וחיפוש דירות להשכרה, למכירה ולהחלפה זמנית, המיועד בין היתר לציבור החרדי. אבקש לבדוק את האתר ולאפשר גישה אליו בכפוף למדיניות הסינון שלכם.

כתובת האתר המדויקת: [תושלם לאחר פריסה].

תיאור הפעילות: מודעות דירות, בחירת יעד ותאריכים בבורר עברי, תמונות נכסים והתכתבות בין משתמשים לצורך תיאום. קיימים טופסי הרשמה והתחברות. המשתמשים יכולים להעלות תוכן, ולכן אבקש בדיקה לפי מדיניותכם ואינני מצהירה שכל תוכן המשתמשים נבדק מראש.

לצורך ניהול האתר נדרשת לי גם גישה לשירותים הבאים:

- לוח ניהול האירוח: https://app.northflank.com/
- מאגר המקור: https://github.com/ayal408/domix
- ניהול תמונות: חשבון Cloudinary; קישור הניהול המדויק יושלם לאחר פתיחת החשבון.
- תמונות באתר: נתיב החשבון המדויק תחת https://res.cloudinary.com/ יושלם לאחר הגדרתו.

בקשות ההתחברות וה־API וכן הודעות WebSocket פועלות דרך אותו מקור של האתר, ב־HTTPS וב־WSS. בסיס הנתונים אמור להישאר פרטי ונגיש לשרת בלבד; אין צורך לפתוח אותו לגלישה ציבורית. אין בבקשה זו צורך בפתיחה גורפת של כלל `code.run` או של כלל שירותי אחסון התמונות.

אם נדרשים פרטים טכניים נוספים או בדיקת קבצים מסוימים, אשמח לספק כתובות מדויקות. אין לצרף לפנייה סיסמאות, מפתחות API, מחרוזות חיבור או קישורים עם אסימוני התחברות.

תודה רבה.
