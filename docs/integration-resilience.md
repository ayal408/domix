# אמינות API ואינטגרציות

## התחברות

- אסימון רענון נצרך בהכנסה אטומית לטבלת הביטולים, עם אינדקס ייחודי על `Token`.
- תקלה בשרת הנתונים מחזירה `503` ו־`AUTH_TEMPORARILY_UNAVAILABLE`; הלקוח אינו מוחק התחברות עקב ניתוק רשת או שגיאת זמינות.
- בזמן שחזור ראשוני שנכשל זמנית מוצג כפתור ניסיון נוסף. אין ניחוש הרשאות משתמש.
- Web Locks מסנכרן החלפת עוגייה בין לשוניות בדפדפנים תומכים; בתוך לשונית נשמר single-flight.
- בכניסה עם Google נבדקים חתימה וקהל יעד באמצעות ספריית Google, וכן `email_verified`. חשבון חסום נדחה לפני קישור. קישור אינו מוחק כניסה בסיסמה.
- יש להגדיר את אותו מזהה לקוח ב־`GOOGLE_CLIENT_ID` וב־`VITE_GOOGLE_CLIENT_ID`, ולהוסיף את כתובת האתר ל־Authorized JavaScript origins ב־Google Cloud. הסודות אינם נשלחים לדפדפן.

מגבלה: אובדן התשובה לאחר צריכת אסימון ולפני קבלת העוגייה החדשה עלול לחייב כניסה מחדש. אין חלון שימוש חוזר באסימון ישן. בדפדפן ללא Web Locks אין נעילה משותפת בין לשוניות.

## התראות מייל

התראה נרשמת ב־`SavedSearchEmails` יחד עם קידום סמן החיפוש, באותה טרנזקציה ובנעילת שורת החיפוש. רק התאמות עד זמן החיתוך נכנסות לתקציר.

| מצב | משמעות | התנהגות |
| --- | --- | --- |
| `Pending` | ממתין לשליחה | ניתן לתפוס למשלוח אחד |
| `Sending` | נעשה ניסיון משלוח | לא נשלח שוב על ידי עובד אחר |
| `Sent` | הספק אישר משלוח | לא נשלח שוב |
| `Blocked` | הגדרה חסרה או הרשאה שנדחתה לפני משלוח | חוזר לתור לאחר חיבור או בדיקת מייל מוצלחת |
| `Unknown` | תוצאת המשלוח אינה ידועה | ממתין לבדיקה ידנית; אין ניסיון חוזר אוטומטי |

משלוח שנותר ב־`Sending` יותר מחמש דקות מסומן `Unknown`. אין הבטחת משלוח בדיוק פעם אחת מול Gmail: הפסקת תקשורת אחרי קבלת ההודעה אצל הספק יוצרת תוצאה עמומה. מסך הניהול מציג את המצב הזה במפורש. מחיקת החיפוש מוחקת את משימותיו.

`connected` נשאר שדה תאימות המציין שהוגדרו פרטי חיבור מקומיים. `connectionStatus` ו־`lastCheckedAt` מייצגים את תוצאת הניסיון האחרון, ואינם בדיקת זמינות בזמן אמת. ניתוק במסך משבית שליחה מקומית; הוא אינו מבטל את ההרשאה בחשבון Google.

מגבלה: מצב ההסכמה הזמני של חיבור Gmail נשמר בזיכרון של מופע השרת, לעשר דקות. בפריסה עם כמה מופעים נדרשת הצמדה לאותו מופע או העברת המצב למאגר משותף. הפעלה מחדש במהלך ההסכמה דורשת התחלת החיבור מחדש.

## חיפוש

`GET /api/Apartment/Search` ו־`GET /api/Apartment/all` מקבלים `offset` ו־`pageSize` בטווח 1–100. ברירת המחדל היא 100. הצורה נשארה מערך JSON. יש מיון יציב עם `ApartmentId` כשובר שוויון.

הקטלוג טוען 24 מודעות בכל לחיצה על טעינת תוצאות נוספות. מסכי ניהול ומפה שעדיין זקוקים לרשימה מלאה משתמשים במתאם העובר על עמודים; הם עדיין עשויים לצרוך זיכרון רב בכמויות גדולות. לקוח חיצוני שקרא את הרשימה המלאה בבקשה אחת צריך לעבור על עמודים. בכתיבות מקבילות, עימוד לפי היסט עשוי לזוז בין בקשות.

כלי החיפוש בצ׳אט מעביר חצאי חדרים ו־`listingType`, ומגביל את שאילתת מסד הנתונים לשמונה תוצאות.

## אימות

- לקוח: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` מתוך `domix-client`.
- אימות: `npm test` מתוך `auth-server`.
- שרת: `dotnet test domix-server.Tests`.
- אינטגרציה: `npm test` מתוך `integration-tests` מול מסד בדיקות ריק. הבדיקה מוחקת את נתוני מסד הבדיקות בתחילתה.
- בדיקות Google ביחידה ובדפדפן משתמשות בתשובות מדומות. יש להשלים כניסה אמיתית ושליחת בדיקה עם חשבון מורשה לאחר הגדרת הסביבה.
